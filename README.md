# Pack Pal

A mobile app for iOS and Android that helps users create, customize, and reuse packing lists for backpacking, car camping, mountaineering, and other outdoor adventures.

## Overview
Adventure Packing Lists allows users to create reusable packing lists for different types of trips. Users can maintain standard lists containing their essential gear and create custom trip variations that automatically add items based on specific conditions, seasons, or personal preferences.

Instead of building a new packing list for every adventure, users can start with their standard gear list and apply a trip-specific variation.

## Core Features

### Multiple Packing Lists
- Create, edit, and delete multiple packing lists.
- Organize lists by activity, such as backpacking, car camping, or mountaineering.
- Reuse existing lists for future trips.

### Custom Trip Variations
- Create custom variations of a standard packing list.
- Each variation includes all core items plus additional gear for specific trip conditions.
- Users can name variations however they choose.

---

Example:

**Standard Backpacking List**
- Backpack
- Tent
- Sleeping bag
- Backpacking stove
- Water filter
- First aid kit

**Shoulder Season Variation**
Includes everything from the Standard Backpacking List, plus:
- Microspikes
- Insulated jacket
- Winter gloves
- Additional warm layers
 
When a user selects the "Shoulder Season" variation, the additional items automatically appear alongside their standard gear.

### Packing Progress

- Check off items as they are packed.
- Track packing progress for each trip.
- Reset packing checkboxes after a trip without deleting or modifying the saved list.

### Reusable and Customizable
- Add, edit, or remove items from packing lists.
- Create multiple variations for different trip conditions.
- Maintain consistent core gear across trips while customizing additional equipment.

## Example User Workflow
1. Create a standard backpacking packing list.
2. Add essential gear used on most backpacking trips.
3. Create a variation called "Shoulder Season."
4. Add seasonal items such as microspikes and additional insulation.
5. Select the standard backpacking list and apply the "Shoulder Season" variation.
6. Check off items while preparing for the trip.
7. Reset the packing checklist after returning home, preserving the list for future adventures.

## Target Platforms
- iOS
- Android

## Project Goal
Provide outdoor enthusiasts with a simple, flexible packing list system that reduces repetitive planning, helps prevent forgotten gear, and makes preparing for different types of adventures easier.
